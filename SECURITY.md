# Security Policy

## Supported versions

SCRYMR is pre-alpha. Only the latest commit on `main` is currently supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when available. Do not open a public issue containing exploit details, credentials, bot tokens, personal data, or live server evidence.

Include the affected component, reproduction steps, impact, and a safe proof of concept. Maintainers will acknowledge valid reports as capacity permits.

## Operator responsibilities

- Grant the bot only the permissions required for enabled features.
- Keep the bot token outside source control.
- Start in dry-run mode.
- Review policy changes before deployment.
- Obtain appropriate consent before enabling content collection or retention.
